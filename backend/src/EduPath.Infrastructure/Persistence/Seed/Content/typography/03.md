## 45–75 знаків у рядку

Читаючи, око не ковзає рядком плавно, а стрибає по кілька слів. Наприкінці рядка воно має повернутися
на початок наступного. Довгий рядок змушує око губитися при переході на наступний — людина перечитує
той самий рядок або пропускає один. Короткий рядок рве ритм читання: переходів забагато, і текст
сприймається уривками.

Комфортна довжина для основного тексту — **45–75 знаків** з пробілами, оптимум близько 65.
Для дрібного тексту й підписів рядок може бути коротшим, для широких таблиць — це правило не діє.

## Як обмежити в CSS

```css
.prose {
  max-width: 68ch;
}
```

Одиниця `ch` дорівнює ширині символу «0» поточного шрифту, тож обмеження автоматично підлаштовується
під кегль і гарнітуру. Типова помилка — обмежити ширину всього контейнера сторінки: тоді разом
з текстом звужуються таблиці й картки. Обмежуйте саме блоки тексту.

На широкому екрані порожнє місце збоку від тексту — це нормально. Його можна заповнити змістом
статті, навігацією або просто залишити повітря.

## Інтерліньяж

Інтерліньяж (`line-height`) — відстань між базовими лініями рядків.

| Текст | line-height |
|---|---|
| Основний текст, 14–18 px | 1,4–1,6 |
| Дрібні підписи | 1,3–1,4 |
| Заголовки | 1,1–1,25 |
| Великі заголовки, 40 px+ | 1,0–1,1 |

Для основного тексту — 1,4–1,6. Що довший рядок, то більший інтерліньяж потрібен оку, щоб не загубити
наступний рядок. Для заголовків менше, 1,1–1,25: великі кеглі з широким інтерліньяжем розсипаються,
і заголовок у два рядки читається як два окремі.

```css
body { line-height: 1.55; }
h1, h2, h3 { line-height: 1.15; }
```

Записуйте `line-height` без одиниць — тоді значення множиться на розмір шрифту кожного елемента,
а не успадковується як фіксовані пікселі.

## Абзаци й вирівнювання

- **Відступ між абзацами** — приблизно 0,75–1 висоти рядка. Відступ першого рядка в інтерфейсі не потрібен.
- **Вирівнювання за лівим краєм.** Вирівнювання за шириною у вебі без якісних переносів створює
  «річки» з пробілів, особливо у вузьких колонках і в мовах з довгими словами.
- **Центрування** — лише для коротких фрагментів у два-три рядки: заголовки, порожні стани.
  Довгий центрований текст важко читати, бо кожен рядок починається в новому місці.

## Контраст тексту

Сірий текст на білому виглядає елегантно на макеті і погано читається на дешевому екрані під сонцем.
Основний текст має контраст щонайменше 4,5 : 1 до фону (WCAG AA), великі заголовки — 3 : 1.
Перевіряйте контраст у Figma або DevTools, а не на око.

## Практика

Відкрийте найдовшу текстову сторінку свого продукту: статтю, урок, умови використання. Порахуйте знаки
в рядку на десктопі й телефоні, перевірте інтерліньяж і контраст. Виправте те, що виходить за межі,
і порівняйте, наскільки легше читається.
