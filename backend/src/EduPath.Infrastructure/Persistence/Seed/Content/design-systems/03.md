## Макет, що поводиться як CSS Flexbox

Статичний макет ламається, щойно змінюється вміст: довша назва курсу вилазить за картку, кнопка з
перекладеним текстом налазить на сусідню. Auto Layout задає не координати, а **правила** розташування —
так само, як Flexbox у браузері. Розробник бачить у макеті ту саму логіку, яку напише в CSS.

## Основні налаштування

- **Напрямок** — вертикальний чи горизонтальний (`flex-direction: column | row`).
- **Відступ між елементами** (`gap`) — одне значення з системи відступів, а не різні відстані вручну.
- **Внутрішні поля** (`padding`) — окремо по горизонталі й вертикалі.
- **Вирівнювання** — 9 позицій, як `justify-content` і `align-items`.
- **Spacing mode: Space between** — елементи розносяться по краях (`justify-content: space-between`).

## Поведінка розміру: Hug, Fill, Fixed

Для кожного елемента й контейнера окремо по ширині й висоті:

| Figma | CSS | Значення |
|---|---|---|
| **Hug contents** | `width: auto` / `fit-content` | розмір за вмістом |
| **Fill container** | `flex: 1` / `width: 100%` | займає доступний простір |
| **Fixed** | `width: 320px` | фіксований розмір |

Картка з `Fill` по ширині й `Hug` по висоті поводиться в Figma так само, як у браузері: розтягується
на ширину колонки, а висота росте разом із текстом.

```css
.card {
  display: flex;
  flex-direction: column;
  gap: 8px;
  padding: 16px 20px;
  width: 100%;
}
```

## Обмеження

**Min / Max width** не дають елементу стати занадто вузьким чи широким — аналог `min-width` і `max-width`.
Наприклад, кнопка має `Hug` по ширині, але не менше 96 px, а текстовий блок у картці — `Fill`,
але не ширше 68 символів.

**Wrap** переносить елементи на новий рядок, коли вони не вміщуються, — як `flex-wrap: wrap`.
Підходить для тегів, фільтрів, сітки карток.

**Absolute position** виводить елемент з потоку — бейдж «Новий» у куті картки (`position: absolute`).

## Перевіряйте на крайніх випадках

Перед передачею макета розтягніть і стисніть фрейм, підставте в текстові шари:

- дуже довгу назву без пробілів;
- переклад англійською — він зазвичай на 20–30 % коротший, німецькою — довший;
- порожнє значення;
- число з шести цифр.

Якщо макет пережив усе це без ручного виправлення, у коді він теж поводитиметься передбачувано.

## Адаптивні макети

Auto Layout не замінює брейкпоінти, але робить кожен компонент гнучким. Сторінку для мобільного
збирають з тих самих компонентів, змінюючи напрямок контейнера (горизонтальний → вертикальний)
і кількість колонок. Окремі «мобільні версії» компонентів зазвичай не потрібні.

## Практика

Візьміть картку курсу або товару зі свого макета, перебудуйте її повністю на Auto Layout і перевірте
на чотирьох крайніх випадках зі списку. Порівняйте налаштування з CSS, який напише розробник.
